| Input Type      | Common Validations                                                              |
| ----------------| ------------------------------------------------------------------------------- |
|  text           | required, minLength, maxLength, pattern, trim spaces                            |
|  email          | required, valid email format, maxLength                                         |
|  password       | required, minLength, maxLength, uppercase, lowercase, number, special character |
|  number         | required, min, max, integer/decimal validation                                  |
|  tel            | required, phone format, length                                                  |
|  url            | required, valid URL format                                                      |
|  date           | required, min date, max date, future/past date, date formate                    |
|  datetime-local | required, date-time range                                                       |
|  time           | required, valid time range                                                      |
|  month          | required, valid month                                                           |
|  week           | required, valid week                                                            |
|  search         | same as text                                                                    |
|  textarea       | required, minLength, maxLength                                                  |
|  radio          | required selection                                                              |
|  checkbox       | required (if mandatory), min/max selections                                     |
|  select         | required selection                                                              |
|  file           | required, file type, file size, file count                                      |
|  color          | valid color value                                                               |
|  range          | min, max, step                                                                  |
|  hidden         | usually server-side validation only                                             |
-----------------------------------------------------------------------------------------------------


VALIDATION LIST WITH ERROR MESSAGES

GENERAL

* Required → "This field is required."
* Empty after trim → "This field cannot be empty."
* Min Length → "Must be at least {min} characters."
* Max Length → "Cannot exceed {max} characters."
* Exact Length → "Must be exactly {length} characters."
* Invalid Characters → "Contains invalid characters."
* Special Characters Not Allowed → "Special characters are not allowed."
* Numbers Not Allowed → "Numbers are not allowed."
* Letters Only → "Only letters are allowed."
* Alphanumeric Only → "Only letters and numbers are allowed."

NUMBER

* Invalid Number → "Enter a valid number."
* Positive Number Only → "Value must be greater than 0."
* Non-Negative Number → "Value cannot be negative."
* Integer Only → "Value must be a whole number."
* Decimal Not Allowed → "Decimal values are not allowed."
* Min Value → "Value must be at least {min}."
* Max Value → "Value cannot exceed {max}."
* Range → "Value must be between {min} and {max}."
* Multiple Of → "Value must be a multiple of {value}."
